Clase 9: 2do Trabajo integrador
Proyecto:  Trabajo en Grupo (2 a 3 integrantes) –  Modelado de un modelo entidad relación y sus consultas 

Descripción del Proyecto: 
Se requiere la maquetación del diseño de un modelo entidad relación como la creación de su base de datos y tablas vinculadas a las acciones de creación, listado, modificación y eliminación para un proyecto orientado a la creación de listas de tareas de diferentes usuarios. El desarrollo de este proyecto permitirá a los usuarios gestionar una lista de tareas. 

Los usuarios podrán agregar nuevas tareas, marcar tareas como completadas, editar tareas existentes y eliminar tareas. 

Tareas a realizar 
-Elección del motor de base de datos 
-Creación del modelo entidad / relación 
-Creación de la base y tablas asociadas (Opcional) 
-Creación de las sentencias SQL para las acciones solicitadas
